When a question asks about "top customers," "top products," or similar,
and the relevant table has a name/description column (e.g. customer_name,
product_name, material_name), always SELECT and GROUP BY that name column
instead of (or in addition to) the raw ID column. Only use the raw ID if
the user explicitly asks for it.

When a query involves month-level or period-level grouping across multiple
years (e.g. monthly trends, month_num, month_short), always ORDER BY the
full chronological sequence -- typically fiscal_year then month_num, or a
true date/sequence column -- never ORDER BY month_num alone, since that
groups all Januaries together before any February regardless of year.

When ordering results chronologically across multiple years (e.g. monthly
trends spanning fiscal years), always ORDER BY year first, then month --
for example ORDER BY fiscal_year, month_num -- never ORDER BY month_num
alone, since that groups every January together before any February
regardless of year.
